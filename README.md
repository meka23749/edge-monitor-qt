# Edge Monitor Qt Dashboard 
Real-time system monitoring dashboard built with C++ and Qt. 
## Features 
- Real-time CPU temperature, CPU usage, RAM and disk monitoring 
- Native Qt desktop application (no browser needed) 
- Visual alarm indicators with color-coded status 
## Tech Stack 
- Language: Modern C++ 
- Framework: Qt 6 (Widgets) 
- Build: CMake
